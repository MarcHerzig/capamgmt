# VM Kapazitätsplaner

Web-App zur Planung von VM-Migrationen und Host-Kapazität.

## Start

```bash
npm install
npm run dev
```

Öffne http://localhost:1420

## Features

- Kunden mit VMs verwalten
- Host-Kapazität pro Cluster (Singlesite B/Z, ITBC)
- Migrations-Timeline mit Host-Einbau-Planung
- Export/Import (JSON)
